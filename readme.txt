=== BeBrand Site ===
Requires at least: 5.8
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPL-2.0-or-later

Shows the BeBrand website on the home page and receives its project briefs and call requests.

== What it does ==
* The home page of the site becomes the BeBrand page, exactly as designed. The theme is not used for it.
* "Start your project" and "Book a call" send to this WordPress: each request is saved under Project requests and emailed.
* Settings > BeBrand Site: switch the home page on or off, and choose the address requests are emailed to.

== Notes ==
* Photographs: the sky is "Kloofendal 48d Partly Cloudy (Pure Sky)" from Poly Haven (CC0). The home and room pictures are stock photographs.
* If requests show "No (saved here only)" under "Emailed to you", WordPress could not send mail from this host. Add an SMTP plugin or ask the host.
